## Directory Purposes

**src/**
- Purpose: Vue 3 TypeScript application source code
- Contains: Components, stores, composables, types, utils, assets
- Key files: `main.ts`, `App.vue`

**src/components/**
- Purpose: Reusable UI building blocks for the game screen
- Contains: GameScreen, MenuScreen, ResponseButtons, GameTimer, ScoreDisplay, GameOverDisplay
- Key files: `GameScreen.vue` (main gameplay), `MenuScreen.vue` (config)

**src/composables/**
- Purpose: Vue composition functions that manage complex reactive logic and side effects
- Contains: useGameLifecycle (Capacitor integration), useFeedback (toast), useAnimations (visual effects)
- Key files: `useGameLifecycle.ts` (app state sync), `useFeedback.ts` (response feedback)

**src/stores/**
- Purpose: Pinia store modules for global state management
- Contains: gameStore (game logic), audioStore (sound), persistenceStore (storage)
- Key files: `gameStore.ts` (core engine), `persistenceStore.ts` (data persistence)

**src/types/**
- Purpose: TypeScript type definitions (no runtime code)
- Contains: Stimulus interface, game enums, state types
- Key files: `game.ts` (all game types)

**src/utils/**
- Purpose: Utility functions, thin wrappers around external APIs
- Contains: haptics (Capacitor Haptics), sentry (error tracking)
- Key files: `haptics.ts` (no-throw device vibration)

**src/assets/**
- Purpose: Audio files used by audioStore
- Contains: WAV and MP3 sound files
- Key files: `stimulus.wav`, `ting.mp3`, `whip.mp3`

**dist/**
- Purpose: Built web app output (generated by Vite)
- Contains: Bundled HTML, CSS, JS, audio, images
- Generated: Yes (run `npm run build`)
- Committed: No (in .gitignore)

**ios/App/**
- Purpose: iOS native app wrapper (Capacitor)
- Contains: AppDelegate, Xcode project, Swift code
- Key files: `AppDelegate.swift` (UIKit entry point)

**android/app/**
- Purpose: Android native app wrapper (Capacitor)
- Contains: MainActivity (Kotlin/Java), Gradle build, resources
- Key files: `MainActivity.java` (Android entry point)

**public/**
- Purpose: Static assets served by Vite dev server and copied to dist/
- Contains: Favicon, app manifest, icon images
- Key files: `manifest.json` (PWA manifest)

**e2e/**
- Purpose: End-to-end tests using Playwright
- Contains: Test files for full app workflows

**__mocks__/**
- Purpose: Test doubles for Capacitor plugins
- Contains: Mock implementations for vitest

**.planning/codebase/**
- Purpose: GSD codebase analysis documents
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, STACK.md, INTEGRATIONS.md

## Key File Locations

**Entry Points:**
- `index.html`: Web browser entry point (loads src/main.ts)
- `src/main.ts`: Vue app initialization (creates app, installs Pinia, mounts to #app)
- `ios/App/App/AppDelegate.swift`: iOS app launch entry
- `android/app/src/main/java/com/polynback/MainActivity.java`: Android app launch entry

**Configuration:**
- `capacitor.config.ts`: Capacitor platform config (app ID, web directory, native platform settings)
- `vite.config.js`: Vite build configuration (plugins, path aliases)
- `tsconfig.json`: TypeScript compiler options
- `package.json`: Project metadata and npm dependencies

**Core Logic:**
- `src/stores/gameStore.ts`: Game engine (stimulus gen, scoring, game loop)
- `src/stores/audioStore.ts`: Audio playback system
- `src/stores/persistenceStore.ts`: Data persistence (Capacitor Preferences + localStorage)

**Testing:**
- `src/stores/__tests__/`: Store unit and integration tests
- `e2e/`: End-to-end tests

## Naming Conventions

**Files:**
- **Vue components:** PascalCase + `.vue` extension (e.g., `GameScreen.vue`, `ResponseButtons.vue`)
- **TypeScript/Logic:** camelCase + `.ts` extension (e.g., `useGameLifecycle.ts`, `gameStore.ts`)
- **Configuration:** camelCase or kebab-case + extension (e.g., `vite.config.js`, `.prettierrc`)
- **Tests:** filename + `.test.ts` or `.spec.ts` (e.g., `gameStore.test.ts`)

**Directories:**
- **Component dirs:** lowercase (e.g., `components/`, `stores/`, `composables/`)
- **Feature dirs:** descriptive names (e.g., `__tests__/`)
- **Utility dirs:** short descriptive names (e.g., `utils/`, `types/`, `assets/`)

**TypeScript:**
- **Types:** PascalCase (e.g., `Stimulus`, `HighScoreData`, `StimulusAttribute`)
- **Functions:** camelCase (e.g., `respondToStimulus()`, `setNewStimulus()`)
- **Constants:** UPPER_SNAKE_CASE (e.g., `maxHistory`)
- **Variables:** camelCase (e.g., `currentStimulus`, `isAudioEnabled`)

**Vue:**
- **Props:** camelCase in script, kebab-case in template (Vue 3 convention)
- **Events:** camelCase (e.g., `@respond`, `@update:nBackInput`)
- **Component names:** PascalCase everywhere (imports, exports, templates)

## Where to Add New Code

**New Feature (Game Mode, New Stimulus Type):**
- Primary code: `src/stores/gameStore.ts` (logic)
- UI rendering: New component in `src/components/` or root `src/`
- Types: Add to `src/types/game.ts`
- Tests: New file in `src/stores/__tests__/` (integration test)

**New Component/Modal:**
- Implementation: `src/` root if screen-level (e.g., `src/NewScreenModal.vue`) or `src/components/` if part of GameScreen
- Import in: `src/App.vue` if modal, or parent component
- Composable support: Create in `src/composables/` if needs complex logic (e.g., animation, lifecycle)

**New Utility/Helper:**
- Shared helpers: `src/utils/` (no-throw wrappers, thin platform abstraction)
- Validation logic: `src/types/` (keep near types if validation is simple) or new file in `src/utils/`

**New Store:**
- Location: `src/stores/newStore.ts`
- Pattern: Use `defineStore()` from Pinia, composition API (setup function)
- Return: All state (refs), computed, and actions
- Tests: Parallel test file `src/stores/__tests__/newStore.test.ts`

**Tests:**
- Unit tests: Co-located with stores in `src/stores/__tests__/`
- Component tests: Alongside components (e.g., `src/components/GameScreen.test.ts`)
- Integration tests: `src/stores/__tests__/` (e.g., `gameFlow.integration.test.ts`)
- E2E tests: `e2e/` directory

## Special Directories

**dist/:**
- Purpose: Vite build output
- Generated: Yes (run `npm run build`)
- Committed: No (in .gitignore)
- Contents: Built HTML, bundled CSS/JS, audio files, images
- Served by: Capacitor WebView (specified in capacitor.config.ts as webDir: 'dist')

**node_modules/:**
- Purpose: npm installed dependencies
- Generated: Yes (npm install)
- Committed: No (in .gitignore)
- Contents: All npm packages (Vue, Pinia, Capacitor, Vite, etc.)

**ios/ and android/:**
- Purpose: Native app wrappers generated and managed by Capacitor
- Generated: Initially by Capacitor CLI; updated by `capacitor sync`
- Committed: Yes (native code changes, Xcode/Gradle config)
- Contents: Swift/Kotlin code, Xcode/Gradle config, compiled artifacts

**__mocks__/:**
- Purpose: Mock implementations for vitest (testing without native Capacitor plugins)
- Generated: Manual (created by developer)
- Committed: Yes
- Contents: Stub modules for @capacitor/app, @capacitor/preferences, etc.

**e2e/:**
- Purpose: End-to-end tests (Playwright)
- Generated: Manual (test files written by developer)
- Committed: Yes
- Contents: .spec.ts files describing full user workflows

**.planning/codebase/:**
- Purpose: GSD documentation (this architecture analysis)
- Generated: Manual (by GSD map tool)
- Committed: Yes
- Contents: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, STACK.md, INTEGRATIONS.md
