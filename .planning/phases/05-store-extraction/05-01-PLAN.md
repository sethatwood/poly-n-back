**audioStore.js (~70 lines):**

2. Use plain `let` variables (NOT refs) for `context` and `buffers` -- these hold non-serializable AudioContext/AudioBuffer objects. Do NOT return them from the store.
3. Expose `ready` and `unlocked` as `ref()` -- these ARE reactive and needed by consumers.
4. Import sound URLs at top level (same as current gameStore.js lines 4-6):
   ```javascript
   import stimulusSoundUrl from '../assets/stimulus.wav';
   import incrementSoundUrl from '../assets/ting.mp3';
   import strikeSoundUrl from '../assets/whip.mp3';
   ```
5. `init()` function: Same logic as current audioManager.init() -- create AudioContext, load all sounds via Promise.allSettled, set ready.value = true. On failure, set ready.value = false and warn.
6. `loadSound(name, url)` function: Same as current audioManager.loadSound(). Internal only (don't return it).
7. `unlock()` function: Same as current audioManager.unlock(). Resume suspended context, set unlocked.value = true.
8. `play(soundName)` function: Same as current audioManager.play(). Guard with ready check, resume if suspended, create buffer source, connect, start.
9. Call `init()` at the end of the setup function BEFORE the return statement (preserving eager initialization behavior from current line 72).
10. Return: `{ ready, unlocked, init, unlock, play }`.

**persistenceStore.js (~65 lines):**
Extract persistence helpers from gameStore.js lines 121-171 into a Pinia store. Key implementation details:

1. Use `defineStore('persistence', () => { ... })` with Pinia setup syntax.
2. Import `{ Preferences } from '@capacitor/preferences'`.
3. `migrated` ref (boolean, default false) -- tracks whether localStorage migration has run.
4. `loadPreference(key, defaults)` async function: Identical logic to current gameStore lines 121-142. Read from Preferences, parse JSON, validate schema (type match + required keys for objects), return defaults on any failure.

6. `migrateFromLocalStorage()` async function: Identical logic to current gameStore lines 152-171. Check `_migrated` flag first, migrate keys (highScoreData, isAudioEnabled, achievements, tutorialCompleted), set `_migrated` flag, update `migrated.value = true`. Note: localStorage references here are INTENTIONAL (reading old data for migration -- per project decision from Phase 4).
7. Return: `{ migrated, loadPreference, savePreference, migrateFromLocalStorage }`.
