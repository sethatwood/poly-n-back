For each store: rename .js to .ts (use `git mv`), then add type annotations. Fix all imports that reference the old .js files throughout the codebase.

**audioStore.js -> audioStore.ts:**
- Import `type { SoundName }` from `@/types/game`
- Type `context` as `AudioContext | null` (plain let variable, not ref)
- Type `buffers` as `Record<string, AudioBuffer>` (plain let variable, not ref)
- Type `loadSound` params: `(name: string, url: string): Promise<void>`
- Type `init`: `(): Promise<void>`
- Type `unlock`: `(): void`
- Type `play` param: `(soundName: SoundName): void`
- Handle `webkitAudioContext`: `const AudioCtx = window.AudioContext || (window as any).webkitAudioContext` (per research -- non-standard Safari prefix needs cast)
- Add explicit return type annotation or let it be inferred (Pinia setup stores have good inference)

**persistenceStore.js -> persistenceStore.ts:**
- Type `loadPreference` as generic: `async function loadPreference<T>(key: string, defaults: T): Promise<T>`
- Type `savePreference` as generic: `async function savePreference<T>(key: string, data: T): Promise<void>`
- Type `migrateFromLocalStorage`: `(): Promise<void>`
- The `parsed` variable from `JSON.parse(value)` should be typed as `unknown`, then validated before returning as `T`
- In schema validation loop: cast `defaults as Record<string, unknown>` and `parsed as Record<string, unknown>` for object key checking

**gameStore.js -> gameStore.ts:**
- Import types: `import type { Stimulus, HighScoreData, RespondedThisTurn, FeedbackState, StimulusAttribute, SoundName } from '@/types/game'`
- Type all refs with generics:
  - `currentStimulus = ref<Stimulus>({ color: 'purple', emoji: 'fire', position: 'left', shape: 'circle' })` -- give a valid initial value instead of empty object `{}`
  - `deterministicStimuli = ref<Stimulus[]>([...])` for the deterministic stimuli array
  - `highScoreData = ref<HighScoreData>({ score: 0, potentialCorrectAnswers: 0, nBack: null })`
  - `respondedThisTurn = ref<RespondedThisTurn>({ color: false, emoji: false, position: false, shape: false })`
  - `lastFeedback = ref<FeedbackState>({ type: null, button: null, timestamp: null })`
  - `stimulusHistory = ref<Stimulus[]>([])`
  - `timer = ref<ReturnType<typeof setInterval> | null>(null)` -- use ReturnType pattern per research to avoid Node vs browser type conflict
  - All boolean and number refs can use inference (e.g., `ref(false)` infers `Ref<boolean>`)
- Type function parameters:
  - `generateRandomStimulus(): Stimulus`
  - `setNewStimulus(): void`
  - `playSound(soundName: SoundName): void`
  - `startGame(timeLeftParam: number = 5): void`
  - `respondToStimulus(stimulusType: StimulusAttribute): void`
  - All other functions: add `: void` return types
- The `currentStimulus` initial value MUST change from `ref({})` to `ref<Stimulus>({ color: 'purple', emoji: 'fire', position: 'left', shape: 'circle' })` or another valid Stimulus. An empty object `{}` is not assignable to `Stimulus` under strict mode.
