**Step 3: Rewrite gameStore.js to setup syntax**

The audioManager singleton at the top of the file stays EXACTLY as-is (it is module-level code, not part of the store). The sound asset imports also stay unchanged.

Rewrite the `defineStore('game', { ... })` call to use the setup function form: `defineStore('game', () => { ... })`.

**Migration rules (from RESEARCH.md):**

1. **Every `state()` property** becomes a `ref()` with the same initial value:
   - `currentStimulus: {}` -> `const currentStimulus = ref({})`
   - `highScoreData: JSON.parse(...)` -> `const highScoreData = ref(JSON.parse(...))`
   - `respondedThisTurn: { color: false, ... }` -> `const respondedThisTurn = ref({ color: false, ... })`

2. **Every getter** becomes a `computed()`:
   - `isEarlyInGame: (state) => { ... }` -> `const isEarlyInGame = computed(() => { ... })` with `state.X` replaced by `X.value`

3. **Every action** becomes a plain function:
   - `startGame(timeLeft = 5) { this.unlockAudio(); ... }` -> `function startGame(timeLeft = 5) { unlockAudio(); ... }`
   - ALL `this.X` references become `X.value` (for refs) or just `X()` (for calling other functions)
   - `this.playSound('stimulus')` becomes `playSound('stimulus')` (same closure scope)

4. **setInterval callback in startGame** -- The `this.isPaused`, `this.timeLeft`, etc. references inside the interval callback become `isPaused.value`, `timeLeft.value`, etc.

5. **setTimeout in setNewStimulus** -- `this.flashBorder = false` becomes `flashBorder.value = false`.

6. **CRITICAL: Return statement** -- ALL state refs, computed properties, and functions MUST be returned. Compare against the current options API to ensure nothing is missed. The return object must include:
   ```javascript
   return {
     // state (refs)
     currentStimulus, deterministicIndex, deterministicStimuli, flashBorder,
     highScoreData, incorrectResponses, isNewHighScore, showGameOverModal,
     isAudioEnabled, isDeterministic, isPaused, isStopped, level,
     timerInterval, nBack, potentialCorrectAnswers, previousPotentialCorrectAnswers,
     respondedThisTurn, lastFeedback, score, stimulusHistory, timeLeft, timer,
     // getters (computed)
     isEarlyInGame, finalScoreAccuracy, highScoreAccuracy,
     // actions (functions)
     generateRandomStimulus, setNewStimulus, toggleAudio, unlockAudio,
     playSound, toggleDeterministicMode, resetGameState, dismissGameOverModal,
     resetHighScore, startGame, pauseGame, resumeGame, stopGame, respondToStimulus,
   };
   ```

7. **Do NOT change** the audioManager singleton, the sound imports, or any game logic. This is purely a syntax migration -- same behavior, different API style.

8. **Add `ref` and `computed` to the vue import:**
   ```javascript
   import { ref, computed } from 'vue';
   import { defineStore } from 'pinia';
   ```
