  <action>
Execute the following steps in order. Verify the app builds after each major step.

**Step 1: Create .nvmrc**
Create `.nvmrc` with content `22` (just the major version number, no newline fuss).

**Step 2: Verify Node 22 is active**
Run `node -v` and confirm it shows v22.x. If not, run `nvm use 22` or `nvm install 22` first.

**Step 3: Upgrade Vue**
Run: `npm install vue@^3.5.29`
This is a drop-in upgrade with zero breaking changes from 3.3.

**Step 4: Upgrade Vite and plugin-vue**
Run: `npm install -D vite@^7.3.1 @vitejs/plugin-vue@^6.0.4`
The existing vite.config.js (just `plugins: [vue()]`) needs no changes for Vite 7.

**Step 5: Verify build works**
Run: `npm run build`
Must complete with zero errors. If there are warnings about `process.env.NODE_ENV`, that is expected and will be fixed in the next step.

**Step 6: Remove dead dependencies**
Run: `npm uninstall postcss autoprefixer register-service-worker @vue/cli-plugin-pwa`

**Step 7: Delete registerServiceWorker.js**
Delete `src/registerServiceWorker.js` entirely.

**Step 8: Fix main.js**
In `src/main.js`:
1. Remove the line `import './registerServiceWorker'`
2. Replace `if (process.env.NODE_ENV === 'development')` with `if (import.meta.env.DEV)` -- Vite uses `import.meta.env` for client-side environment detection, not `process.env`.

The final main.js should look like:
```javascript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import { useGameStore } from './store/gameStore';
import './style.css'
import App from './App.vue'

const app = createApp(App);

const pinia = createPinia();
app.use(pinia);

app.mount('#app');

// For debugging: Bind gameStore to the window object
if (import.meta.env.DEV) {
  window.gameStore = useGameStore();
}
```

**Step 9: Fix postcss.config.js**
Remove the `autoprefixer: {},` line from the plugins object. Keep only `tailwindcss: {}`. The file should be:
```javascript
export default {
  plugins: {
    tailwindcss: {},
  },
}
```

**Step 10: Regenerate lockfile**
Delete `package-lock.json` and run `npm install` fresh. This produces a clean v3 lockfile without stale Vite 4 resolution trees. Per user decision -- this is mandatory.

**Step 11: Verify build again**
Run `npm run build` -- must succeed with zero errors.
