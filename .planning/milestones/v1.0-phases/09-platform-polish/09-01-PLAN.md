     - Export three async functions: `hapticsCorrect()`, `hapticsIncorrect()`, `hapticsGameOver()`

     - `hapticsIncorrect`: calls `Haptics.notification({ type: NotificationType.Warning })`
     - `hapticsGameOver`: calls `Haptics.notification({ type: NotificationType.Error })`
     - Each function wraps the call in try-catch (no-throw) so haptics failure never affects gameplay
     - NO preference check inside the utility -- the call site gates on `isHapticsEnabled`

     - Add `toggleHaptics()` function following the exact `toggleAudio()` pattern:
       ```typescript
       function toggleHaptics(): void {
         isHapticsEnabled.value = !isHapticsEnabled.value;

       }
       ```
     - In `respondToStimulus()`, after the `playSound('increment')` line, add:
       `if (isHapticsEnabled.value) hapticsCorrect();`
     - In `respondToStimulus()`, after `playSound('strike')` line, add:

     - Import `hapticsCorrect, hapticsIncorrect, hapticsGameOver` from `@/utils/haptics`
     - Return `isHapticsEnabled` and `toggleHaptics` from the store setup function

     - Create async function `setupAppStateListener()` inside the composable:
       ```typescript
       async function setupAppStateListener(): Promise<void> {
         appStateListener = await App.addListener('appStateChange', ({ isActive }) => {
           if (!isActive && !gameStore.isStopped && !gameStore.isPaused) {
             gameStore.pauseGame();
           }
           // Do NOT auto-resume -- user must tap Resume explicitly
         });
       }
       ```
     - Call `setupAppStateListener()` at composable setup time (fire-and-forget, no await needed)
