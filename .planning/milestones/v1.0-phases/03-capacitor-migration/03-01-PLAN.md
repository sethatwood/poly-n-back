This task performs the full Capacitor 5 to 8 migration in a single pass. Follow this exact order:

**Step 1: Update npm packages**

Install all four Capacitor packages at ^8.1.0:

```bash
npm install @capacitor/core@^8.1.0 @capacitor/cli@^8.1.0 @capacitor/ios@^8.1.0 @capacitor/android@^8.1.0
```

Verify installation: `npx cap --version` should report 8.x.

**Step 2: Create capacitor.config.ts**

Create `capacitor.config.ts` in the project root with this exact content:

```typescript
import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'com.polynback',
  appName: 'Poly N-Back',
  webDir: 'dist',
  server: {
    androidScheme: 'https',
  },
  android: {
    backgroundColor: '#0f1729',
  },
  ios: {
    backgroundColor: '#0f1729',
  },
};

export default config;
```

Key decisions reflected:
- App ID changed from `fun.polynback` to `com.polynback` (user decision -- aligns with future polynback.com domain)
- `server.androidScheme: 'https'` kept explicitly (matches Cap 5 config and Cap 8 default -- prevents any data loss risk)
- Background color `#0f1729` preserved (dark blue theme)
- `appName` set to `Poly N-Back` (proper display name with space, not the npm package name)

**Step 3: Delete old config**

Delete `capacitor.config.json` (replaced by the .ts version above).

**Step 4: Build web assets**

Run `npm run build` to produce `dist/` directory. Capacitor needs this before `cap add`.

**Step 5: Delete old native projects**

```bash
rm -rf ios/ android/
```

These will be regenerated fresh by Cap 8 CLI. No custom native code exists.

**Step 6: Add fresh iOS project with SPM**

```bash
npx cap add ios --packagemanager SPM
```

This creates a new `ios/` directory with Swift Package Manager (not CocoaPods). SPM is the Cap 8 default for new projects.

**Step 7: Add fresh Android project**

```bash
npx cap add android
```

This creates a new `android/` directory with Cap 8's required Gradle 8.14.3, AGP 8.13.0, compileSdk 36, targetSdk 36.

**Step 8: Sync web assets into native projects**

```bash
npx cap sync
```

This copies `dist/` into both native projects and resolves all Capacitor dependencies.
