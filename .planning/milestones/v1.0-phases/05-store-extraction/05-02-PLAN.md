Delete `loadPreference()`, `savePreference()`, and `migrateFromLocalStorage()` functions entirely. These now live in persistenceStore.

**Step 5: Update loadPersistedState()**
Replace:
```javascript

```
With:
```javascript
async function loadPersistedState() {
  await persistenceStore.migrateFromLocalStorage();

  isAudioEnabled.value = await persistenceStore.loadPreference('isAudioEnabled', true);
}
```

**Step 6: Update audio functions**


Replace `playSound()`:

**Step 7: Update persistence calls in actions**
