**vitest.config.ts** — Create at project root. Use a SEPARATE config file (not merged into vite.config.js) to avoid TypeScript config conflicts with Vite 7. Include:
- `plugins: [vue()]` (import from @vitejs/plugin-vue)
- `resolve.alias`: `{ '@': fileURLToPath(new URL('./src', import.meta.url)) }`
- `test.globals: true` (required for @pinia/testing createSpy auto-detection)
- `test.environment: 'happy-dom'`
- `test.include: ['src/**/*.test.ts']`
- `test.setupFiles: ['./src/test-setup.ts']`
- `test.coverage.provider: 'v8'` and `test.coverage.include: ['src/stores/**', 'src/composables/**']`

Do NOT include `@tailwindcss/vite` in the vitest plugins — it's not needed for tests and would add overhead.

**src/test-setup.ts** — Global setup that runs before each test file. Must provide:
1. `globalThis.AudioContext` — A class-based mock (not just an object) so `new AudioCtx()` works in audioStore. Properties: `state: 'running'`, `resume()` returning Promise.resolve(), `decodeAudioData()` returning Promise.resolve({} as AudioBuffer), `createBufferSource()` returning `{ buffer: null, connect: vi.fn(), start: vi.fn() }`, `destination: {}`.
2. `globalThis.fetch` — Mock returning `Promise.resolve({ arrayBuffer: () => Promise.resolve(new ArrayBuffer(0)) })`.
3. `globalThis.localStorage` — A minimal mock with `getItem`, `setItem`, `removeItem` (returns null/undefined) since persistenceStore.migrateFromLocalStorage accesses localStorage.

Import `vi` from 'vitest' for the mock functions.

CRITICAL: These stubs MUST exist before any store module is imported, which is why they go in setupFiles (runs before test file imports). This prevents audioStore's eager `init()` call from crashing with "AudioContext is not defined".

**__mocks__/@capacitor/preferences.ts** — Manual mock file at project root `__mocks__/@capacitor/` directory. Provides an in-memory Map-based implementation:
```typescript
const store = new Map<string, string>();

export const Preferences = {
  async get(opts: { key: string }): Promise<{ value: string | null }> {
    return { value: store.get(opts.key) ?? null };
  },
  async set(opts: { key: string; value: string }): Promise<void> {
    store.set(opts.key, opts.value);
  },
  async remove(opts: { key: string }): Promise<void> {
    store.delete(opts.key);
  },
  async clear(): Promise<void> {
    store.clear();
  },
  _reset(): void {
    store.clear();
  },
};
```
