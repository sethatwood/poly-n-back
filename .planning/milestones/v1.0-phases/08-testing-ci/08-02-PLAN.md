**Test suites (describe blocks) and specific test cases:**

**1. `describe('stimulus generation')`**
- `it('generateRandomStimulus returns valid Stimulus')` — Call `store.generateRandomStimulus()`. Assert returned object has color in ['purple','green','blue'], emoji in ['fire','ice','flower'], position in ['left','center','right'], shape in ['circle','square','triangle'].
- `it('deterministic mode cycles through deterministicStimuli')` — Set `store.isDeterministic = true`, call `store.startGame(5)`. The first stimulus is set during resetGameState->setNewStimulus. Assert `store.currentStimulus` matches `store.deterministicStimuli[0]`. Advance timer to trigger next setNewStimulus (advance 5000ms). Assert `store.currentStimulus` matches `store.deterministicStimuli[1]`.
- `it('setNewStimulus pushes to stimulusHistory')` — Start game, check `stimulusHistory.length` increases after each timer cycle (advance timerInterval * 1000ms).

**2. `describe('response evaluation')`**
- `it('correct match increments score')` — Use deterministic mode. Start game. Advance enough turns (nBack+1 intervals) so nBackIndex >= 0. Inspect `stimulusHistory` to find a matching attribute between current and nBack-ago stimulus. Call `respondToStimulus(matchingAttribute)`. Assert `store.score` increased by 1.
- `it('incorrect response increments strikes')` — Same setup but respond with a non-matching attribute. Assert `store.incorrectResponses` increased by 1.
- `it('debounce prevents double response on same attribute in same turn')` — Start game, advance past nBack. Call `respondToStimulus('color')` twice. Assert `store.respondedThisTurn.color === true` and total score/strikes changed only once (check sum of score + incorrectResponses increased by exactly 1, not 2).
- `it('response before nBack history is available is ignored')` — Start game but do NOT advance timer (stimulusHistory has only 1 entry). Call `respondToStimulus('color')`. Assert score and incorrectResponses both still 0.

**3. `describe('score calculation')`**
- `it('finalScoreAccuracy returns 0 when no potential answers')` — Fresh store, `previousPotentialCorrectAnswers = 0`. Assert `store.finalScoreAccuracy === 0`.
- `it('finalScoreAccuracy calculates correct percentage')` — Set `store.score = 3` and `store.previousPotentialCorrectAnswers = 10` manually. Assert `store.finalScoreAccuracy === 30`.
- `it('highScoreAccuracy returns 0 when no high score potential')` — Assert `store.highScoreAccuracy === 0` on fresh store.
- `it('highScoreAccuracy calculates from highScoreData')` — Set `store.highScoreData = { score: 5, potentialCorrectAnswers: 20, nBack: 2 }`. Assert `store.highScoreAccuracy === 25`.

**4. `describe('turn management')`**
- `it('startGame initializes timer and game state')` — Call `store.startGame(5)`. Assert `store.isStopped === false`, `store.isPaused === false`, `store.timerInterval === 5`, `store.timeLeft === 5`, `store.timer !== null`.
- `it('timer decrements timeLeft each second')` — `startGame(5)`. Advance 1000ms. Assert `timeLeft === 4`. Advance another 1000ms. Assert `timeLeft === 3`.
- `it('timer triggers setNewStimulus when timeLeft reaches 1')` — `startGame(3)`. Advance 2000ms (timeLeft goes 3->2->1 at the tick). At that tick, setNewStimulus fires and timeLeft resets to 3. Assert `store.stimulusHistory.length > 1`.
- `it('pauseGame prevents timer from progressing')` — Start, advance 1s, pause, record timeLeft. Advance 3s more. Assert timeLeft unchanged.
- `it('resumeGame allows timer to continue')` — Start, pause, resume, advance 1s. Assert timeLeft decremented.
- `it('stopGame clears interval and sets isStopped')` — Start, stop. Assert `store.isStopped === true`. Advance 5s. Assert timeLeft unchanged (timer cleared).
- `it('stimulus history is capped at nBack + 50')` — Start game. Advance enough timer cycles to push 60+ stimuli (with nBack=2, cap is 52). Assert `store.stimulusHistory.length <= 52`.

**5. `describe('high score logic')`**
- `it('game over after 3 strikes')` — Use deterministic mode with nBack=2. Start game. Advance past nBack. Make 3 intentionally wrong responses (respond on attributes that don't match). Assert `store.isStopped === true` and `store.showGameOverModal === true`.
- `it('new high score saved when score exceeds current')` — Set `store.highScoreData = { score: 0, potentialCorrectAnswers: 0, nBack: null }`. Drive game to game over with score > 0. Assert `store.isNewHighScore === true` and `store.highScoreData.score > 0`.
- `it('resetHighScore clears high score data')` — Set highScoreData to non-zero. Call `store.resetHighScore()`. Assert `store.highScoreData.score === 0`.
- `it('dismissGameOverModal hides modal')` — Set `store.showGameOverModal = true`. Call `store.dismissGameOverModal()`. Assert `store.showGameOverModal === false`.

NOTE: For deterministic mode tests, the executor should inspect `store.deterministicStimuli` to determine which attributes match at each nBack step. The default deterministicStimuli array is:
```
[0]: { color: 'blue', emoji: 'flower', position: 'center', shape: 'square' }
[1]: { color: 'green', emoji: 'ice', position: 'left', shape: 'triangle' }
[2]: { color: 'blue', emoji: 'fire', position: 'right', shape: 'circle' }
```

IMPORTANT: `startGame(timeLeft)` calls `resetGameState()` which calls `setNewStimulus()` — so stimulusHistory gets its first entry immediately on `startGame()`. Each subsequent interval tick at `timeLeft === 1` adds another entry.

Create `src/stores/__tests__/audioStore.test.ts`.

This is the trickiest store to test because `init()` fires eagerly at import time. The test-setup.ts provides a baseline AudioContext stub that prevents crashes, but individual tests need to verify specific behaviors.

**Approach:** Since the audioStore calls `init()` during module evaluation, and Vitest caches modules, use `vi.resetModules()` between test groups that need different AudioContext behavior. Each `describe` block that needs a fresh audioStore should:
1. Call `vi.resetModules()` in beforeEach
2. Re-stub `globalThis.AudioContext` and `globalThis.fetch` with test-specific behavior
3. Dynamically import `useAudioStore` to get a fresh instance
4. Wrap in `setActivePinia(createPinia())` before the dynamic import

**Test suites:**

**1. `describe('successful initialization')`**
- `it('sets ready=true when AudioContext and sounds load successfully')` — Use the default stubs (from test-setup.ts). Dynamically import useAudioStore. Assert `store.ready === true`.
- `it('loads all three sound buffers')` — Spy on `globalThis.fetch`. After store init, assert fetch was called 3 times (stimulus.wav, ting.mp3, whip.mp3).

**2. `describe('initialization failure')`**
- `it('sets ready=false when AudioContext constructor throws')` — Stub `globalThis.AudioContext` to throw Error. `vi.resetModules()`, re-import. Assert `store.ready === false`.
- `it('sets ready=false when AudioContext is not available')` — Delete `globalThis.AudioContext` (set to undefined). `vi.resetModules()`, re-import. Assert `store.ready === false`.
- `it('remains ready=true even when individual sound fails to load')` — Stub fetch to reject for one URL and resolve for others (use `mockImplementation` that checks the URL). `vi.resetModules()`, re-import. Assert `store.ready === true` (Promise.allSettled means partial failures are tolerated).

**3. `describe('graceful degradation - play()')`**
- `it('play is a no-op when ready is false')` — Get store where init failed (ready=false). Call `store.play('stimulus')`. Assert no error thrown.
- `it('play is a no-op when context is null')` — Same as above but verify through the ready check.

**4. `describe('unlock')`**
- `it('unlock resumes suspended AudioContext')` — Create store with AudioContext.state = 'suspended'. Spy on the context's `resume` method. Call `store.unlock()`. Assert resume was called. Assert `store.unlocked === true`.
- `it('unlock is a no-op when already unlocked')` — Call `store.unlock()` twice. Assert second call doesn't re-invoke resume (or is harmless).
- `it('unlock is a no-op when not ready')` — Get store with ready=false. Call `store.unlock()`. Assert `store.unlocked === false`.

IMPORTANT: For dynamic import pattern, use:
```typescript
const { useAudioStore } = await import('@/stores/audioStore');
const store = useAudioStore();
```
This ensures the module is freshly evaluated after `vi.resetModules()`.
