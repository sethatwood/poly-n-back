From src/composables/useGameLifecycle.ts:
```typescript
export function useGameLifecycle(gameStore: GameStore): {
  showModal: Ref<boolean>;          // true = menu screen, false = game screen
  startGame: (timeLeftInput: number) => void;   // sets showModal=false, calls gameStore.startGame
  handlePause: () => void;           // calls gameStore.pauseGame
  handleResume: () => void;          // calls gameStore.resumeGame
  handleQuit: () => void;            // resumeGame + stopGame + showModal=true
  handleGameOverClose: () => void;   // calls gameStore.dismissGameOverModal
  handlePlayAgain: (timeLeftInput: number) => void;  // dismissGameOverModal + startGame
  handleMainMenu: () => void;        // dismissGameOverModal + showModal=true
}
```

IMPORTANT: useGameLifecycle uses `onUnmounted` which requires a component lifecycle context. For testing, either:
1. Mount a minimal wrapper component that calls the composable, OR
2. Test the lifecycle functions directly without the onUnmounted cleanup (acceptable for integration tests since we manually call stopGame in afterEach)

Create `src/stores/__tests__/gameFlow.integration.test.ts`.

These tests use REAL store instances (gameStore, audioStore, persistenceStore all wired together). Only external APIs are mocked (via test-setup.ts globals + __mocks__/@capacitor/preferences.ts).

**Mock setup at top:**
```typescript
vi.mock('@capacitor/preferences');  // uses __mocks__ auto-resolution
```
Do NOT mock audioStore or persistenceStore — that's the whole point of integration tests.

**beforeEach:**
```typescript
setActivePinia(createPinia());
vi.useFakeTimers();
```

**afterEach:**
```typescript
vi.clearAllTimers();
vi.useRealTimers();
// Reset Preferences mock store
const { Preferences } = await import('@capacitor/preferences');
(Preferences as any)._reset();
```

**Test cases:**

**1. `describe('full game flow: start -> play -> game over')`**

- `it('complete game from start to game over via 3 strikes')` — This is the most important integration test. Steps:
  1. `const gameStore = useGameStore()` — this triggers audioStore and persistenceStore setup internally
  2. `gameStore.isDeterministic = true` and `gameStore.nBack = 2`
  3. `gameStore.startGame(3)` — starts with 3-second interval
  4. Assert initial state: `isStopped === false`, `score === 0`, `incorrectResponses === 0`, `stimulusHistory.length === 1` (setNewStimulus called during resetGameState)
  5. Advance timer to build up nBack history: `vi.advanceTimersByTime(3000)` twice (2 more stimuli). Now stimulusHistory has 3 entries.
  6. Inspect stimulusHistory to find a non-matching attribute between current (index 2) and nBack-ago (index 0). The deterministic stimuli at index 0 and 2 differ on emoji (flower vs fire), position (center vs right), and shape (square vs circle) but share color (blue). So `respondToStimulus('emoji')` is incorrect.
  7. Call `gameStore.respondToStimulus('emoji')` — incorrectResponses becomes 1
  8. Advance timer another 3000ms for next turn
  9. Inspect current vs nBack-ago again for another incorrect response. Call respondToStimulus with a non-matching attribute.
  10. Repeat for third strike
  11. Assert: `gameStore.isStopped === true`, `gameStore.showGameOverModal === true`, `gameStore.incorrectResponses === 3`

- `it('score increments on correct matches across real stores')` — Use deterministic mode. With nBack=2, stimuli[0].color === stimuli[2].color === 'blue'. After 2 advances, call `respondToStimulus('color')`. Assert `gameStore.score === 1`. Verify audio was triggered (audioStore.play was called internally — we can check that no errors occurred since play() is real but uses our stubbed AudioContext).

- `it('high score persists to Preferences on game over')` — Start game, drive to game over with some score. After game over, use `Preferences.get({ key: 'highScoreData' })` to verify the high score was actually written to the (mocked) Preferences store.

- `it('loadPersistedState restores high score from Preferences')` — Pre-populate Preferences with `{ key: 'highScoreData', value: '{"score":10,"potentialCorrectAnswers":20,"nBack":2}' }`. Create fresh store, call `loadPersistedState()`. Assert `gameStore.highScoreData.score === 10`.

- `it('audio toggle persists across stores')` — `gameStore.toggleAudio()`. Assert `gameStore.isAudioEnabled === false`. Verify `Preferences.get({ key: 'isAudioEnabled' })` returns `{ value: 'false' }`.

These tests verify the state machine transitions that drive the UI (menu -> game -> pause -> resume -> game over -> menu). They test the useGameLifecycle composable with a real gameStore.

**Mock setup at top:**
```typescript
vi.mock('@capacitor/preferences');
```

**Approach for testing useGameLifecycle:** Since `onUnmounted` requires a Vue component instance, use a test helper that creates a minimal component context. Import `withSetup` utility or create inline:
```typescript
import { createApp } from 'vue';
import { createPinia, setActivePinia } from 'pinia';

function withSetup<T>(composable: () => T): { result: T; app: ReturnType<typeof createApp> } {
  let result!: T;
  const app = createApp({
    setup() {
      result = composable();
      return () => {};
    },
  });
  app.use(createPinia());
  app.mount(document.createElement('div'));
  return { result, app };
}
```
This gives `onUnmounted` a real lifecycle to hook into.

**Test cases:**

**1. `describe('state transitions: menu -> game -> pause -> resume -> game over -> menu')`**

- `it('startGame transitions from menu to active gameplay')` — Use `withSetup` to create gameStore and lifecycle. Assert `showModal.value === true` (starts on menu). Call `lifecycle.startGame(5)`. Assert `showModal.value === false` (on game screen). Assert `gameStore.isStopped === false`, `gameStore.isPaused === false`.

- `it('handlePause transitions to paused state')` — Start game. Call `lifecycle.handlePause()`. Assert `gameStore.isPaused === true`. Advance timer. Assert timeLeft hasn't decremented (paused timer skips).

- `it('handleResume returns to active gameplay')` — Start, pause, resume. Assert `gameStore.isPaused === false`. Advance timer. Assert timeLeft decrements normally.

- `it('handleQuit returns to menu from paused state')` — Start, pause. Call `lifecycle.handleQuit()`. Assert `showModal.value === true` (back to menu). Assert `gameStore.isStopped === true`.

- `it('game over triggers modal, handleMainMenu returns to menu')` — Start game with deterministic mode. Drive 3 strikes. Assert `gameStore.showGameOverModal === true`. Call `lifecycle.handleMainMenu()`. Assert `gameStore.showGameOverModal === false`. Assert `showModal.value === true` (back to menu).

- `it('handlePlayAgain starts new game from game over')` — Drive to game over. Call `lifecycle.handlePlayAgain(5)`. Assert `gameStore.showGameOverModal === false`. Assert `showModal.value === false` (still on game screen). Assert `gameStore.isStopped === false` (new game started).

- `it('handleGameOverClose dismisses modal without navigation')` — Drive to game over. Call `lifecycle.handleGameOverClose()`. Assert `gameStore.showGameOverModal === false`. Assert `showModal.value === false` (still on game screen, no navigation).

- `it('full cycle: menu -> start -> pause -> resume -> game over -> play again -> game over -> main menu')` — The full round-trip test. Execute the entire sequence and verify state at each step. This is the integration test that catches state leaks.

**2. `describe('cleanup')`**

- `it('unmounting stops the game timer')` — Use `withSetup`. Start game. Assert timer is running. Call `app.unmount()`. Assert the timer was cleaned up (advance time, timeLeft shouldn't change since stopGame was called by onUnmounted).
