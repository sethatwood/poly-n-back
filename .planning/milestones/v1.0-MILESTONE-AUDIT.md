1. **GameState type orphaned** (informational) — `src/types/game.ts` exports `GameState` but no file imports it. The state machine exists via boolean refs. Could be removed or wired.

2. **Sentry DSN placeholder** (informational) — `.env.production` has empty `VITE_SENTRY_DSN=`. PROD builds without a DSN run with no error handler at all. **Action:** Fill `.env.production.local` with a real Sentry DSN before release.

3. **isHapticsEnabled not in migration keys** (informational) — New Phase 9 key has no localStorage-era data. `loadPersistedState()` correctly loads from Preferences with `false` default. No user-visible impact.

4. **LINT-CI-GAP** (RESOLVED) — The previous audit identified 20 ESLint errors and missing lint in CI. Phase 10 resolved this: all `eslint-disable` comments have justifications, `vue/block-lang` re-enabled, `npm run lint:check` in CI.
